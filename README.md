## people4 invoice api cli

The cli using the authentication api cli

python (requires Python 3.12+, run from the repository root)
```bash
python3.12 -m venv .venv
source .venv/bin/activate
python python/people4_invoice_cli.py
deactivate
```

PHP
```bash
php php/People4InvoiceCli.php 
```

JAVA (requires OpenJDK 17+, run from the repository root)
```bash
javac -d java --release 17 java/People4InvoiceClient.java
java -cp java People4InvoiceClient
```
